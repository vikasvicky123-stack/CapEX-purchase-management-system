\# AI-Assisted CapEx Purchase Management System



\## 1. Project Overview

The AI-Assisted CapEx Purchase Management System is a prototype application developed using Python and Streamlit.



It provides features to manage capital expenditure purchase requests, budget allocation, accounting and depreciation, asset inventory, AI-assisted CapEx classification and invoice data extraction.



\## 2. Technologies Used

\- Python

\- Streamlit

\- SQLite

\- Pandas

\- Pillow

\- Tesseract OCR

\- Pytesseract



\## 3. Main Modules



1\. Purchase Request Management

2\. Budget Management

3\. Accounting and Depreciation

4\. Asset Inventory Management

5\. AI-Assisted CapEx Classification

6\. Invoice OCR and JSON Extraction

7\. Dashboard



\## 4. System Requirements

\- Windows operating system

\- Python 3.10 or above

\- Required Python libraries

\- Tesseract OCR installed separately



\## 5. Installation Instructions



\### Step 1: Install Python

Download and install Python from:

https://www.python.org/downloads/



During installation, enable the option "Add Python to PATH".



\### Step 2: Install Tesseract OCR

Download and install Tesseract OCR.



The application uses Tesseract OCR for invoice text extraction.



\### Step 3: Install Required Libraries

Open Command Prompt inside the project folder and execute:



pip install -r requirements.txt



\### Step 4: Run the Application

Execute the following command:



streamlit run app.py



The application will open in your default web browser.



\## 6. Database

The application uses SQLite for storing application records.



The database is maintained locally within the project.



\## 7. Important Notes

\- This project is an academic prototype.

\- Sample records are used for demonstration and testing.

\- CapEx classification provides preliminary recommendations and requires human verification.

\- OCR-extracted invoice information should be manually verified.

\- Tesseract OCR must be installed separately from the Python libraries.
